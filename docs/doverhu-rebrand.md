# Ребрендинг «Доверху» и политика конфиденциальности

Название сайта обновлено со «Сладкий Дар» на «Доверху»; шапка, футер, метаданные страниц, иконки браузера и заголовки новых уведомлений ВКонтакте используют новый бренд. Домен и репозиторий остаются прежними.

Политика перенесена из предоставленного оператором DOCX редакции 24.09.2026 с заменой названия сервиса. ИНН 771771661209 и ОГРНИП 321774600775832 централизованы в `apps/web/src/shared/config/site.ts`.

Новые заявки сохраняют версию согласия `2026-09-24`. Миграция изменяет только значение по умолчанию столбца `consent_version`; ранее сохранённые согласия и содержимое заявок остаются прежними.

Технические имена Compose, баз данных, volumes, SSH-псевдонимов и каталогов релизов сохранены. Ключ sessionStorage также сохранён, чтобы посетителям повторно не показывалась уже закрытая автоматическая форма из-за смены бренда.
